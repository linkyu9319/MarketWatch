### 实测发现的重要映射与边界问题（已在代码中规避）
1. **纳斯达克 100 代码陷阱**：东方财富 `100.NDX` 实际返回的是**纳斯达克综合指数 (IXIC, 23585.80)**，真正的纳斯达克 100 为 **`100.NDX100` (26046.90)**；腾讯侧 `usSPX` 无返回，标普 500 必须映射为 **`us.INX`**。两者均已通过跨源价格比对修正。
2. **东方财富盘前 `"-"` 占位符**：09:00–09:30 开盘前，东方财富对尚未产生成交的标的返回 `"f2":"-"` 而 `f18` 为昨收。解析器严格将 `"-"` 映射为 `null`（绝不填 `0`），并由聚合器自动回退腾讯备源补全昨收价格与昨收时间。
3. **编码与时区差异**：
   - 腾讯 `qt.gtimg.cn` 响应为 `GBK`（代码页 936 / `GB18030`）；港股时间为 `yyyy/MM/dd HH:mm:ss` (UTC+8)，A 股为 `yyyyMMddHHmmss` (UTC+8)，美股为 `yyyy-MM-dd HH:mm:ss`（**美东时间 EST/EDT**，已按 `Eastern Standard Time` 自动处理夏令时）。
   - 东方财富 `push2` 为标准 UTF-8 JSON，`f124` 为 Unix 秒级时间戳。
4. **分时接口实测**：
   - 东方财富 `push2.eastmoney.com/api/qt/stock/trends2/get`：支持 **港股（开盘后 09:30 起实时累积）**、**A 股（开盘后实时累积）** 及 **美股（391 点完整分钟曲线，含 `100.NDX100` / `105.QQQ` / `105.NVDA`）**；盘前返回空数组 `[]`，UI 如实提示“尚未开盘或暂无分时”，绝不虚构点位。
   - 腾讯 `web.ifzq.gtimg.cn/appstock/app/minute/query`：支持 A 股（242+ 点）与港股（开盘后实时累积）；美股仅返回 1 个收盘点，因此 `TencentQuoteProvider` 对美股显式声明不支持分时，由聚合器统一路由至东方财富。
5. **搜索接口实测**：
   - 东方财富 `searchapi.eastmoney.com/api/suggest/get` 返回精确 `QuoteID`（如 `124.HSTECH`、`100.NDX100`、`106.BABA`），支持直接定位纽交所/纳斯达克/港股/A股；腾讯 `smartbox.gtimg.cn` 作为搜索兜底备源。

## 4. 使用条款与合规边界说明
- 本软件默认使用的腾讯财经与东方财富公开行情端点面向个人桌面查看，**不绕过任何登录鉴权、付费墙、反爬校验或区域限制**。
- 默认轮询周期为 **10 秒**（限制在 5–60 秒），采用**单次批量合并请求**而非逐股轮询，并具备非重叠锁、8 秒超时与指数退避（5s → 10s → 20s → 40s → 60s），避免对公开端点造成异常负载。
- 如未来公开端点调整协议、限流或停止开放，核心本地闹钟与强视觉提醒**完全独立运行不受影响**；也可基于 `IQuoteProvider` 扩展接入富途/长桥等官方合规授权 API。
